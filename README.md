# kindle-ocr

自分が購入した Kindle 書籍を、Kindle for Mac の画面キャプチャ + **完全ローカルの OCR**
（macOS Vision framework）でテキスト化し、Claude Code と「本について会話する」ための
個人用ツール / スキルです。

> ⚠️ **使用前に必ず「[利用上の注意](#必ず読んでください利用上の注意)」を読んでください。**
> このツールは著作権法が認める**私的複製の範囲内**での利用のみを想定しています。
> 生成したデータの共有・再配布・公開は著作権侵害です。

## なぜ作ったか

紙の本なら付箋を貼って「あの話どこだっけ」と探せますが、電子書籍は全文検索止まりで、
「この章の主張を要約して」「◯◯と△△の関係を説明して」のように LLM に聞くことが
できません。かといって、購入した書籍の中身を外部の OCR API や LLM にそのまま
送りつけるのは著作権的に許されません。

そこで「**テキスト化は手元の Mac の中だけで完結させ、会話時も必要な箇所だけを読む**」
という構成にしたのがこのツールです。

## 特徴

- **フォーカスを奪わない**: `CGEventPostToPid` で Kindle プロセスに直接キーイベントを
  送るため、キャプチャ中も Mac を普通に使い続けられる（Kindle は背面のままで OK）
- **完全ローカル OCR**: テキスト化は macOS 内蔵の Vision framework で行う。
  書籍の内容がネットワークや外部 API に送られることはない
- **書名の自動整理**: ページ上部の柱から書名を検出し、`~/kindle-library/<書名>/` に
  `pages/`（画像）、`book.md`（本文テキスト）、`index.md`（見出し索引）を自動生成
- **コンテキスト節約**: 会話時は `index.md` で該当範囲を特定してから `book.md` の
  必要な部分だけを読む2段階検索

## 倫理面での設計方針

「技術的にできること」と「やってよいこと」を混同しないよう、次の方針で設計しています。

1. **DRM に触れない**: Kindle の書籍ファイルや通信には一切アクセスせず、画面に
   *表示された*内容を OS 標準の `screencapture` で撮影するだけです。技術的保護手段の
   回避（復号・解除）にあたる処理は含みません
2. **書籍の内容を外部に送らない**: OCR は macOS 内蔵 Vision framework による
   ローカル処理で、このリポジトリのコードにネットワーク通信は存在しません
3. **複製物を「共有しやすく」しない**: 生成データはリポジトリ外の
   `~/kindle-library/` に保存し、`.gitignore` でも誤コミットに保険をかけています。
   エクスポート・共有・一括処理の機能は意図的に実装していません
4. **文字起こしを LLM にやらせない**: 書籍画像の全文文字起こしを Claude 等の
   外部 AI に依頼する運用は禁止しています（`SKILL.md` に明記）。テキスト化は
   ローカル OCR で完結させ、会話時は該当箇所の参照・要約に留めます

## セットアップ

```bash
python3 -m venv .venv
.venv/bin/pip install pyobjc-framework-Quartz pyobjc-framework-Vision
```

macOS の権限（システム設定 → プライバシーとセキュリティ）:

- **画面収録**: 実行するターミナルアプリに付与
- **アクセシビリティ**: 同上

## 使い方

Kindle for Mac で本を開いた状態で（背面で OK、最小化と Space 移動は不可）:

```bash
# 1. 動作確認（横書き本は --key right、縦書き・漫画は --key left）
.venv/bin/python capture.py --test --key right

# 2. 先頭ページまで巻き戻し
.venv/bin/python capture.py --rewind --key right

# 3. 全ページキャプチャ（書名を自動検出して ~/kindle-library/<書名>/pages/ に保存）
.venv/bin/python capture.py --key right

# 4. ローカル OCR → book.md / index.md 生成
.venv/bin/python ocr.py --book ~/kindle-library/<書名>
```

生成されるディレクトリ構成:

```
~/kindle-library/<書名スラッグ>/
├── pages/       # キャプチャ画像（page_0001.png, ...）
├── book.md      # OCR された本文（行高さから見出しを推定して ## を付与）
└── index.md     # 見出し → ページ画像番号の索引
```

あとは Claude Code で `book.md` のある場所を参照しながら質問するだけです。

### Claude Code スキルとして使う

`SKILL.md` はこのパイプラインを Claude Code のスキルとして呼び出すための定義です。
スキルとして登録すると「Kindle の本を取り込みたい」「◯◯（取り込み済みの本）に
ついて教えて」といった依頼で、キャプチャ〜会話までを Claude Code に任せられます。
会話時に `book.md` を丸ごと読まず `index.md` → 該当範囲の2段階で読む作法も
このファイルに書かれています。

## 仕組み

| 段階 | 使用技術 | 備考 |
|---|---|---|
| ページ送り | `CGEventPostToPid` (Quartz) | フォーカス不要でキーイベントを直接送信 |
| 撮影 | `screencapture -l <windowID>` | 背面ウィンドウも撮影可 |
| 終端検知 | 画像ハッシュ比較 + リトライ | UI 写り込み・描画遅延での誤検知対策済み |
| OCR | Vision framework (`VNRecognizeTextRequest`) | ja-JP / en-US、完全ローカル |
| 構造化 | 行高さによる見出し推定 | book.md に `##`、index.md に索引を生成 |

## 制約・既知の制限

- **macOS 専用**です（Quartz / Vision framework / `screencapture` に依存）。
  Windows / Linux 対応の予定はありません
- Kindle ウィンドウの**最小化・別 Space への移動は不可**（背面に隠すのは OK）
- OCR の精度は完全ではありません。ルビ・図表・数式・複雑な段組は苦手です
- 図やイラストはテキスト化されません（本文の流れだけが `book.md` に残ります）
- 見開き2ページ表示を想定して左右分割しているため、特殊なレイアウトの本では
  読み順が乱れることがあります
